# THE WEB

THE WEB is an interactive personal investigation of Marvel continuity presented as a detective evidence wall.

Prototype 001 focuses only on the physical wall and its interaction model: spatial exploration, evidence objects, typed relationships, and the feeling of discovering an ongoing investigation. It is a static React/Vite site intended for GitHub Pages. It uses placeholder evidence rather than downloaded or scraped comic artwork.

## Development

```bash
npm install
npm run dev
```

The production build is configured for `https://sparshsunilnaik.github.io/THE-WEB/`.
